# Arcana room server (self-hosted)

Arcana's online rooms on a server we own (Hetzner), instead of per-use billing on
Cloudflare Durable Objects. Same URLs and WebSocket protocol as the
`arcana-table-rooms` Cloudflare Worker, so the app works with either.

## How it works

- `vendor/room-worker.ts` is the **exact** Cloudflare room Worker (pinned Arcana
  source + `scripts/patch_directed_room_resumption.py`), generated by
  `scripts/sync_room_server_worker.sh`. Do not edit it by hand.
- `src/runtime.mjs` runs that Worker on Node.js by emulating the small part of the
  Durable Object API it uses: one event at a time per room, storage, one alarm,
  WebSocket attachments. Rooms are saved to disk, so a restart keeps every game,
  seat and private seat token; phones reconnect to their seats on their own.
- `src/server.mjs` serves `GET /health` and `GET /room/{CODE}` (WebSocket).
- Players reach it only through **Cloudflare Tunnel** (`rooms.<domain>`). The
  Hetzner firewall blocks all inbound traffic; TLS and DDoS protection are Cloudflare's.

## Tests

`npm test` runs the Worker's own relay test, Chimera's recovery tests
(all-offline, live takeover, repeated takeover) and a server-restart test against
the Node server. CI: `.github/workflows/room-server-tests.yml`.

Load check (Nov 17, one laptop core): 2,500 four-player rooms = 10,000 phones
connected at once, 37,500 relayed 2 KB messages in 1.5 s, about 230 MB memory.

## Setting up / changing the server

- **First setup:** Actions → *Room server — set up Hetzner + Cloudflare* → Run,
  with the hostname (e.g. `rooms.example.com`), or push to `room-server-provision`
  (hostname and region from `config/room-server.env`; region `eu` or `us`).
  Changing the region moves the server safely: the new one must be tested and
  connected before the old one is deleted. Needs repository secrets
  `HCLOUD_TOKEN`, `CLOUDFLARE_ROOMS_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`. Re-running is
  safe: it reuses the tunnel, DNS record and server.
- **Updates:** the server checks the `room-server-live` branch every 5 minutes.
  A new commit is built and **fully tested on the server** first; it switches only
  if every test passes (a failing commit is skipped, the old version keeps running).
- **App address:** `config/room-server.env` → `ROOM_SERVER_HOSTNAME`. The APK/AAB
  build applies it with `scripts/patch_room_server_endpoint.py`; phones that saved
  the old Worker address move to the new one automatically.
- **Moving hosts later:** point the DNS name somewhere else. No app update needed.
- The old Cloudflare Worker stays deployed for installs that have not updated yet.
